* **Mon–Fri:** Follow daily loop.

* **Saturday:** Review weak skills; write a 150–250 word piece (scale to level).

* **Sunday:** Light Spanish media + weekly self-test; plan next week's target.



### Duolingo Pro Workflow



```text

  [1. Speak Aloud] ──► [2. Predict First] ──► [3. Curate Phrases]

         ▲                                             │

         │                                             ▼

  [6. Real Convo]  ◄── [5. Delayed Test]  ◄── [4. Log Error Why]

```



1. Complete the next lesson, but say every sentence aloud.

2. Before tapping an answer, predict it yourself.

3. Save **useful** new words/phrases in a personal notebook (avoid collecting every word).

4. Review mistakes: write the corrected sentence and the reason.

5. Revisit the same unit after a few days and test recall without hints.

6. Use Duolingo's speaking/listening exercises when available; add real conversation elsewhere.



> **WARNING:** Do not measure mastery by streak, XP, or unit completion alone. Measure what you can understand and produce from memory.

## [01] PRONUNCIATION & READING (A0 → A1)

![LEVEL A0_A1](https://img.shields.io/badge/LEVEL-A0_A1-F78C6B?style=flat-square&labelColor=20243A)  ![SOUND PRONUNCIATION](https://img.shields.io/badge/SOUND-PRONUNCIATION-9B5DE5?style=flat-square&labelColor=20243A)  ![SKILL READING](https://img.shields.io/badge/SKILL-READING-00B4D8?style=flat-square&labelColor=20243A)



Spanish spelling is relatively consistent. Learn the sound system first.



| Letter / Pattern | Approximate Sound | Example |

| :--- | :--- | :--- |

| **a, e, i, o, u** | ah, eh, ee, oh, oo | **casa, mesa** |

| **h** | silent | **hola** |

| **j; ge/gi** | strong breathy "h" (varies by region) | **jamón, gente** |

| **ñ** | "ny" | **niño** |

| **ll, y** | often "y" (regional variation) | **llave, yo** |

| **r** | tap between vowels / at onset | **pero** |

| **rr; initial r** | rolled/trilled r | **perro, rojo** |

| **c + e/i (Spain)** | "th"; Latin America usually "s" | **cinco** |

| **z (Spain)** | "th"; Latin America usually "s" | **zapato** |

| **qu + e/i** | k sound; u silent | **queso** |

| **güe/güi** | pronounce the u | **pingüino** |



### Stress Rules



```text

┌──────────────────────────────────────────────────────────────────────────────┐

│                        SPANISH SYLLABIC STRESS ENGINE                        │

├───────────────────────────────┬───────────────────────────────┬──────────────┤

│ ENDING                        │ STRESS RULE                   │ EXAMPLES     │

├───────────────────────────────┼───────────────────────────────┼──────────────┤

│ Ends in VOWEL, -N, or -S      │ Penultimate (2nd-to-last)     │ CA-sa, HA-blan│

│ Ends in OTHER CONSONANT       │ Final syllable                │ re-LOJ       │

│ Written Accent (á, é, í, ó, ú)│ Overrides default rule        │ ca-FÉ, es-TÁ │

└───────────────────────────────┴───────────────────────────────┴──────────────┘

```



Examples: **casa**, **hablan**, **reloj**, **café**, **inglés**, **está**.



### Accent Marks Are Meaningful



```text

  sí  [yes]       vs.   si  [if]           │   más [more]   vs.   mas [but - literary]

  tú  [you]       vs.   tu  [your]         │   ¿...? / ¡...!      [opening + closing]

  él  [he]        vs.   el  [the]          │

```



### First Speaking Drill



Read slowly, then naturally:

* `Hola. Me llamo ___.`

* `Soy de India.`

* `Estoy aprendiendo español.`

* `¿Cómo estás? Estoy bien, gracias.`

* `Mucho gusto. ¡Hasta luego!`

### Essential Sentence Architecture



```text

  [DECLARATIVE ARCHITECTURE]

  ┌──────────────┐     ┌──────────────┐     ┌────────────────────┐

  │   SUBJECT    │ ──► │     VERB     │ ──► │     COMPLEMENT     │

  │     (Yo)     │     │   estudio    │     │      español.      │

  └──────────────┘     └──────────────┘     └────────────────────┘

   *(Often omitted)     (Ending = Subj)



  [INTERROGATIVE ARCHITECTURE]

  ┌──────────────┐     ┌──────────────┐     ┌────────────────────┐

  │ QUESTION WRD │ ──► │     VERB     │ ──► │ SUBJECT/COMPLEMENT │

  │    ¿Dónde    │     │    vives     │     │       (tú)?        │

  └──────────────┘     └──────────────┘     └────────────────────┘

```



Spanish often omits subject pronouns because the verb ending identifies the subject:

* **(Yo) hablo español.**

* Use **yo** for emphasis or contrast: **Yo hablo; él no.**



### Subject Pronouns



| Person | Singular (Spanish → English) | Plural (Spanish → English) |

| :--- | :--- | :--- |

| **1st Person** | **yo** → I | **nosotros/as** → we |

| **2nd Person (Informal)** | **tú** → you (informal singular) | **vosotros/as** → you plural (mainly Spain) |

| **3rd Person / Formal** | **él / ella / usted** → he / she / you formal | **ellos / ellas / ustedes** → they / you plural (LatAm: **ustedes**) |



### Articles & Gender



```text

                      ┌───────────────────────────┐

                      │     NOUN + AGREEMENT      │

                      └─────────────┬─────────────┘

                    ┌───────────────┴───────────────┐

                    ▼                               ▼

          [MASCULINE (-o / el)]           [FEMININE (-a / la)]

          ├─ Definite   : el libro        ├─ Definite   : la casa

          ├─ Plural     : los libros      ├─ Plural     : las casas

          ├─ Indefinite : un chico alto   ├─ Indefinite : una chica alta

          └─ Indef. Pl. : chicos altos    └─ Indef. Pl. : chicas altas

```



* Gender is grammatical; learn nouns with their article: **la mesa**, not just **mesa**.



### SER vs ESTAR vs HAY



```text

                         ┌────────────────────────┐

                         │  "TO BE" DECISION TREE │

                         └───────────┬────────────┘

                                     │

         ┌───────────────────────────┼───────────────────────────┐

         ▼                           ▼                           ▼

  ┌──────────────┐            ┌──────────────┐            ┌──────────────┐

  │     SER      │            │    ESTAR     │            │     HAY      │

  ├──────────────┤            ├──────────────┤            ├──────────────┤

  │ * Identity   │            │ * State      │            │ * Existence  │

  │ * Origin     │            │ * Condition  │            │  (There is / │

  │ * Inherent   │            │ * Location   │            │   There are) │

  │ * Time       │            │              │            │              │

  ├──────────────┤            ├──────────────┤            ├──────────────┤

  │ Soy estud.   │            │ Estoy cansado│            │ Hay una      │

  │ Somos de Ind.│            │ El libro     │            │ biblioteca.  │

  │ Es lunes.    │            │ está aquí.   │            │ Hay 2 libros.│

  └──────────────┘            └──────────────┘            └──────────────┘

```



**Starter Contrast (Meaning Shifts):**

* **Es aburrido.** = It/he is boring (characteristic) **vs.** **Está aburrido.** = It/he is bored (state).

* **Es listo.** = He is smart **vs.** **Está listo.** = He is ready.

### Stem-Changing Verbs (The "Boot Verb" Pattern)



```text

  THE "BOOT" RULE: Stem changes inside the box; nosotros/vosotros stay outside!

  ┌──────────────────────────┐

  │ yo       quiero          │    nosotros   queremos  (NO CHANGE)

  │ tú       quieres         │    vosotros   queréis   (NO CHANGE)

  │ él/ella  quiere          ├─────────────────────────┐

  │ ellos/as quieren         │  <-- Boot Toe           │

  └──────────────────────────┴─────────────────────────┘



  * e ──► ie : querer ──► quiero, quieres, quiere ... [queremos]

  * o ──► ue : poder  ──► puedo,  puedes,  puede  ... [podemos]

  * e ──► i  : pedir  ──► pido,   pides,   pide   ... [pedimos]

```



### Negation & Questions



* **No** before verb: **No entiendo.**

* Yes/no question: **¿Hablas español?**

* Question words: **qué** (what), **quién** (who), **cuándo** (when), **dónde** (where), **por qué** (why), **cómo** (how), **cuánto/a/os/as** (how much/many), **cuál/es** (which).

* **¿Por qué?** = why; **porque** = because.

## [03] A2: EVERYDAY LIFE & PAST EVENTS

### Past Tense Map



```text

  PAST                                                                 PRESENT

  ════════════════════════════════════════════════════════════════════════╬════►



  1. IMPERFECTO (Background, habit, ongoing past — "was doing / used to")

     ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

     "Estudiaba..." (I was studying...) / "Cuando era niño, llovía mucho."



  2. PRETÉRITO (Completed event / bounded action — "did")

     ──────────────────────────[ X ]─────────────────────────────────

                            "Ayer llovió." / "...cuando llamaste."



  3. PERFECTO COMPUESTO (Past linked to present; usage varies by region)

     ──────────────────────────────────────────────[ X ]═════════════► NOW

                                                   "He terminado."



  4. PRESENT (Now / habit)

     ────────────────────────────────────────────────────────────────► [ NOW ]

```



### Pretérito (Simple Past) Regular Endings



| Person | `-AR` Endings | `-ER / -IR` Endings |

| :--- | :--- | :--- |

| **yo** | `-é` | `-í` |

| **tú** | `-aste` | `-iste` |

| **él / ella / usted** | `-ó` | `-ió` |

| **nosotros/as** | `-amos` | `-imos` |

| **vosotros/as** | `-asteis` | `-isteis` |

| **ellos / ustedes** | `-aron` | `-ieron` |



* **Examples:** **Ayer estudié. Comimos. Vivieron allí.**

* **Common irregular stems:** **tener** → `tuv-`, **estar** → `estuv-`, **hacer** → `hic-` (**hizo**), **ir/ser** → `fui`, **poder** → `pud-`, **poner** → `pus-`, **decir** → `dij-`.



### Imperfecto Endings



| Person | `-AR` Endings | `-ER / -IR` Endings |

| :--- | :--- | :--- |

| **yo** | `-aba` | `-ía` |

| **tú** | `-abas` | `-ías` |

| **él / ella / usted** | `-aba` | `-ía` |

| **nosotros/as** | `-ábamos` | `-íamos` |

| **vosotros/as** | `-abais` | `-íais` |

| **ellos / ustedes** | `-aban` | `-ían` |



* **Only three major irregulars:** **ser** → `era`, **ir** → `iba`, **ver** → `veía`.

* **Contrast:**

  * **Ayer llovió.** = It rained (completed event).

  * **Cuando era niño, llovía mucho.** = It used to rain a lot (background/habit).

  * **Estudiaba cuando llamaste.** = I was studying (imperfect background) when you called (preterite interruption).



### Reflexive Verbs, Gustar & Object Pronouns



```text

  [1] REFLEXIVE VERBS (Subject acts on self)

      Pronouns : me / te / se / nos / os / se

      Example  : Me levanto a las siete. (I get up at seven.)

      Routine  : levantarse, ducharse, vestirse, acostarse, despertarse



  [2] GUSTAR-STYLE VERBS (Thing liked = Subject of the verb!)

      [Indirect Obj] + [Gusta (Sing./Inf.) | Gustan (Plural)] + [Subject]

      * Me gusta  el café.     (Coffee pleases me / I like coffee.)

      * Me gustan los libros.  (Books please me  / I like books.)

      * Me gusta  estudiar.    (Studying pleases me / I like studying.)

      Similar: encantar, interesar, importar, molestar, faltar



  [3] OBJECT PRONOUNS & DOUBLE-PRONOUN COLLISION RULE

      * Direct (DO)   : lo / la / los / las        ("Veo el libro" ──► "Lo veo.")

      * Indirect (IO) : me / te / le / nos / os / les ("Doy el libro a Ana" ──► "Le doy el libro.")

      * Collision Rule: [le / les] + [lo / la / los / las] ──► [SE] + [lo / la / los / las]

                        Example: Le + lo doy ──► "Se lo doy."

```



### Comparisons



* `más ... que` = more ... than

* `menos ... que` = less ... than

* `tan ... como` = as ... as

* `mejor / peor` = better / worse

* `mayor / menor` = older / younger (often age)

### Future & Conditional



```text

  [INFINITIVE BASE] (hablar / comer / vivir)

         │

         ├──► NEAR FUTURE   : ir a + infinitive ──► "Voy a estudiar."

         ├──► SIMPLE FUTURE : Inf + [-é, -ás, -á, -emos, -éis, -án] ──► "Mañana estudiaré."

         └──► CONDITIONAL   : Inf + [-ía, -ías, -ía, -íamos, -íais, -ían] ──► "Me gustaría viajar."



  SHARED IRREGULAR STEMS (Future & Conditional use the exact same stems!):

  decir ──► dir-  | hacer ──► har-   | tener ──► tendr- | poder ──► podr-

  querer ─► querr-| venir ──► vendr- | salir ──► saldr-

```



### Present Perfect



* **Formula:** `haber (he, has, ha, hemos, habéis, han)` + `past participle (-ado / -ido)` → **hablado / comido / vivido**.

* **Example:** **He terminado.** = I have finished.

* **Irregular Participles:** **hecho, dicho, visto, escrito, puesto, vuelto, abierto, muerto**.

* **Regional Note:** Many Latin American speakers commonly use the simple preterite where some Spain speakers use the present perfect.



### Commands (Starter)



* **tú affirmative:** **habla, come, vive**; **irregulars:** `di, haz, ve, pon, sal, sé, ten, ven`.

* **Negative commands use subjunctive:** **No hables. No comas.**

* **Polite (usted):** **Hable, por favor.**



### Subjunctive — The Big Concept



Use it commonly for wishes, doubt, emotion, recommendations, and non-established/desired situations.



```text

  ╔══════════════════════════════════════════════════════════════════════════╗

  ║                    THE SUBJUNCTIVE CIRCUIT ARCHITECTURE                  ║

  ╚══════════════════════════════════════════════════════════════════════════╝



  [CLAUSE 1: MAIN TRIGGER]        [BRIDGE]       [CLAUSE 2: SUBJUNCTIVE VERB]

  * Wish      : Quiero            ┌──────┐       * estudies.   (you study)

  * Emotion   : Espero      ───►  │ QUE  │ ───►  * estés bien. (you are well)

  * Impersonal: Es importante     └──────┘       * practiques. (you practice)

  * Doubt     : Dudo                             * sea verdad. (it is true)



  HOW TO BUILD PRESENT SUBJUNCTIVE:

  [Step 1: "yo" Present Ind.] ──► [Step 2: Drop "-o"] ──► [Step 3: Opposite Endings]

   * hablar ──► hablo         ──►  habl-              ──► -AR takes: -e, -es, -e, -emos, -éis, -en

   * comer  ──► como          ──►  com-               ──► -ER/-IR  : -a, -as, -a, -amos, -áis, -an

   * tener  ──► tengo         ──►  teng-              ──►  tenga

   * hacer  ──► hago          ──►  hag-               ──►  haga

   * Irregs : ir ──► vaya  |  ser ──► sea

```



**Indicative vs. Subjunctive Contrast:**

* `Sé que viene.` (I know he comes/is coming — asserted fact → **Indicative**)

* `Espero que venga.` (I hope he comes — wish → **Subjunctive**)

* `Busco el libro que está aquí.` (Known, specific book → **Indicative**)

* `Busco un libro que sea fácil.` (Unspecified book with desired quality → **Subjunctive**)



### Connectors for Fluent Speech



| Function | Discourse Connectors |

| :--- | :--- |

| **Sequence** | **primero, luego, después, finalmente** |

| **Reason** | **porque, ya que, debido a que** |

| **Result** | **por eso, así que, por lo tanto** |

| **Contrast** | **pero, aunque, sin embargo, mientras que** |

| **Opinion** | **en mi opinión, creo que, desde mi punto de vista** |

| **Examples** | **por ejemplo, es decir, en otras palabras** |

## [07] THE "NEVER CONFUSE THESE" DESK

![FOCUS COMMON_ERRORS](https://img.shields.io/badge/FOCUS-COMMON_ERRORS-F77F00?style=flat-square&labelColor=20243A)  ![METHOD CONTRAST_PAIRS](https://img.shields.io/badge/METHOD-CONTRAST_PAIRS-E76F51?style=flat-square&labelColor=20243A)



### POR vs PARA (Starter Compass)



```text

  PARA (Forward Vector / Goal / Endpoint)       POR (Cause / Medium / Exchange)

  =======================================       =======================================

  [A] ──────────────► ( B: TARGET )             [CAUSE] ──► ( Action )   |  ~~~[ / ]~~~►

   * Destination : para Madrid                   * Movement through : por el parque

   * Purpose     : para estudiar                 * Reason / Cause   : por amor

   * Recipient   : para ti                       * Exchange         : por diez euros

   * Deadline    : para mañana                   * Duration         : por dos horas

```



| PARA (Destination / Goal) | POR (Cause / Route / Exchange) |

| :--- | :--- |

| **Destination:** **para Madrid** | **Movement through:** **por el parque** |

| **Purpose:** **para estudiar** | **Reason/cause:** **por amor** |

| **Recipient:** **para ti** | **Exchange:** **por diez euros** |

| **Deadline:** **para mañana** | **Duration:** **por dos horas** (regional/contextual) |



**This is a useful first map, not every exception.**



### Saber vs Conocer



* **saber** (facts, information, how to do something): **Sé la respuesta; sé nadar.**

* **conocer** (familiarity with people/places): **Conozco a María; conozco Madrid.**



### Muy vs Mucho



* **muy + adjective/adverb:** **muy bueno, muy rápido**

* **mucho + noun / verb:** **mucho dinero, estudio mucho**

* **mucho/a/os/as** agrees with noun: **mucha agua, muchos libros**.



### Desde / Desde Hace / Hace



```text

  [2020] ════════════════════════════► [NOW]   "Vivo aquí desde 2020." (since 2020)

  |<─────────── 3 YEARS ────────────>| [NOW]   "Vivo aquí desde hace tres años." (for 3 yrs)

  [X: Arrived] ◄───── 3 YEARS ──────── [NOW]   "Llegué hace tres años." (3 years ago)

```



### Hay / Está / Están



* **Hay una farmacia.** (existence — a pharmacy exists)

* **La farmacia está cerca.** (location of a specific singular item)

* **Las llaves están en la mesa.** (location of specific plural items)

### Listening Ladder

1. Beginner slow audio with transcript.

2. Familiar-topic videos with Spanish subtitles.

3. Native podcasts with transcript or episode notes.

4. Films/series: first Spanish subtitles, then no subtitles.

5. Different accents: Spain, Mexico, Colombia, Argentina, Caribbean, etc.

* **Method:** `listen for gist` → `identify key phrases` → `replay` → `shadow 20–60 seconds` → `summarize aloud`.



### Speaking Ladder

* **A1:** read sentences aloud

* **A2:** answer daily questions for 1 minute

* **B1:** voice note / monologue for 3–5 minutes

* **B2:** conversation + opinion + follow-up questions

* **C1:** debate, presentation, storytelling

* **C2:** flexible spontaneous conversation with nuance

* **Shadowing:** Listen to one short phrase, pause, imitate rhythm and stress, record yourself, compare. Prioritize intelligibility over trying to erase your accent.



### Reading Ladder

* **A1–A2:** graded readers and short dialogues.

* **B1:** short stories, learner news, accessible articles.

* **B2:** novels, essays, Spanish-language journalism.

* **C1–C2:** literature, specialized texts, satire, poetry, editorial writing.



### Writing Ladder

* **A1:** 5–8 simple sentences about yourself.

* **A2:** routine / past weekend paragraph (80–120 words).

* **B1:** narrative or opinion (150–250 words).

* **B2:** structured argument (300–500 words).

* **C1:** formal essay/report with nuance and style.

* **C2:** polished writing for audience, purpose, and register.

* **Revision Pass Order:** `meaning` → `grammar` → `vocabulary` → `naturalness` → `accents/punctuation`.

![CHECKPOINTS A1_TO_C2](https://img.shields.io/badge/CHECKPOINTS-A1_TO_C2-F4B942?style=flat-square&labelColor=20243A)  ![METHOD PROVE_MASTERY](https://img.shields.io/badge/METHOD-PROVE_MASTERY-E76F51?style=flat-square&labelColor=20243A)



```text

  [A1 GATE] ──► [A2 GATE] ──► [B1 GATE] ──► [B2 GATE] ──► [C1 GATE] ──► [C2 MASTERY]

   (2m Intro)    (Past/Day)    (5m Topic)   (20m Convo)   (Abstract)    (Subtext/Style)

```



### A1 Test

- [ ] Introduce yourself for 2 minutes.

- [ ] Ask and answer 20 basic questions.

- [ ] Understand a slow 1-minute dialogue.

- [ ] Write 80 words about yourself.



### A2 Test

- [ ] Describe your day and family.

- [ ] Narrate yesterday using preterite and imperfect.

- [ ] Handle restaurant / shopping / directions role-play.

- [ ] Understand a short learner podcast.



### B1 Test

- [ ] Speak for 5 minutes on a familiar topic.

- [ ] Explain a problem and propose a solution.

- [ ] Write a 200-word opinion piece.

- [ ] Follow the gist of a normal-speed familiar-topic podcast.



### B2 Test

- [ ] Hold a 15–20 minute conversation.

- [ ] Present a claim with reasons and counterargument.

- [ ] Understand a news segment and summarize it.

- [ ] Write a structured 350-word argument.



### C1 Test

- [ ] Understand a long talk with limited support.

- [ ] Discuss abstract topics spontaneously.

- [ ] Write a coherent formal essay/report.

- [ ] Adapt tone for different audiences.



### C2 Test

- [ ] Interpret subtext, irony, idioms, and rhetorical choices.

- [ ] Understand varied native speakers across genres.

- [ ] Express subtle distinctions precisely.

- [ ] Produce stylistically controlled writing/speech.

## [14] FIRST 30 DAYS — START HERE

![CHALLENGE 30_DAYS](https://img.shields.io/badge/CHALLENGE-30_DAYS-06A77D?style=flat-square&labelColor=20243A)  ![MODE BOOTCAMP](https://img.shields.io/badge/MODE-BOOTCAMP-F4B942?style=flat-square&labelColor=20243A)  ![START A0_A1](https://img.shields.io/badge/START-A0_A1-E76F51?style=flat-square&labelColor=20243A)



```text

  30-DAY BOOTCAMP SPRINT

  ================================================================================

  WEEK 1 [██████░░░░░░░░░░░░░░░░░░] Sounds, Alphabet, Ser, 30s Intro

  WEEK 2 [████████████░░░░░░░░░░░░] Present Verbs (-ar/-er/-ir), Family & Routine

  WEEK 3 [██████████████████░░░░░░] Estar, Hay, Tener, Ir, Restaurant Role-Play

  WEEK 4 [████████████████████████] Boot Verbs, Gustar, Reflexives, 2m Speech

  ================================================================================

```



### Week 1 — Sounds & Introductions

* Alphabet, vowels, stress, greetings.

* Pronouns, **ser**, basic nouns/articles.

* Duolingo daily; read every sentence aloud.

* **Output:** 30-second introduction.



### Week 2 — Present-Tense Basics

* Regular `-ar`/`-er`/`-ir` verbs; questions and negation.

* Numbers, days, time, family.

* **Output:** Describe your family and daily routine in 8–10 sentences.



### Week 3 — Everyday Spanish

* **estar**, **hay**, adjective agreement, **tener**, **ir**.

* Food, home, places, directions.

* **Output:** Restaurant and directions role-play.



### Week 4 — Build and Review

* Stem-changers, **gustar**, reflexive routine verbs.

* Review all mistakes from Weeks 1–3.

* **Output:** Speak for 2 minutes; write 100 words; complete a beginner listening test.



> **DAY 30 CHECKPOINT:** Can you introduce yourself, ask simple questions, talk about routine, understand slow basic speech, and write a short paragraph? If not, repeat/reinforce before rushing forward.

## [15] RULES FOR LONG-TERM MASTERY

![PRINCIPLES 10_RULES](https://img.shields.io/badge/PRINCIPLES-10_RULES-2A9D8F?style=flat-square&labelColor=20243A)  ![FOCUS CONSISTENCY](https://img.shields.io/badge/FOCUS-CONSISTENCY-06A77D?style=flat-square&labelColor=20243A)



1. **Consistency beats intensity.** A manageable daily routine wins.

2. **Understand before memorizing.** Ask what the grammar is doing.

3. **Active recall beats rereading.** Close notes and produce Spanish.

4. **Learn phrases, not only words.**

5. **Speak from day one**, even if only to yourself.

6. **Use comprehensible input:** content should be understandable enough to follow.

7. **Correct recurring errors**, not every tiny mistake at once.

8. **One dialect as your starting anchor is fine**; later expose yourself to many.

9. **Do not translate every sentence word-for-word.** Build direct associations.

10. **CEFR levels are abilities, not app milestones.** Test real-world performance.
